# iOS Directory - Not Maintained

This iOS directory is **not actively maintained** and is **not supported**.

## Scriptoria is Android-Only

Scriptoria is designed exclusively for Android devices and is available only on Google Play Store.

**Why Android-only?**
- Free, ad-free philosophy aligns with Google Play's model
- Lower development costs ($25 one-time vs $99/year)
- Focus on delivering the best Android experience

## For Developers

This directory contains React Native iOS boilerplate but:
- ❌ No iOS-specific development or testing
- ❌ No iOS releases planned
- ❌ No iOS bug fixes or support

If you're interested in contributing iOS support, please open an issue first to discuss the approach and maintenance commitment required.
